# 온라인 리뷰로 본 공무원의 공직 장단점 인식

공무원이 직장 평가 플랫폼에 남긴 리뷰를 구조적 토픽 모델링(STM)으로 분석한 연구의 코드

## 개요

- 리뷰의 장점, 단점 텍스트에서 공무원이 인식하는 공직의 장단점 탐색
- 총 만족도를 공변량으로 넣어 고만족, 저만족 집단의 토픽 언급 비율 비교
- 공공 부문 고용 브랜드와 직원 가치 제안(EVP) 설계의 기초 자료

## 방법 설명

- **구조적 토픽 모델링(STM)**: 문서에 섞여 있는 주제를 자동으로 찾고, 집단(예: 만족도 고저)에 따라 주제 비중이 어떻게 다른지까지 추정하는 텍스트 분석 방법

## 자료

- 온라인 직장 평가 플랫폼의 공무원 리뷰 9,990건 (제목, 장점, 단점, 총점, 세부 평점, 작성 시기)
- 원자료와 수집 코드는 플랫폼 이용 약관에 따라 비공개

## 분석 절차

1. **전처리**: 문장부호와 공백 정리, NLP4kec 형태소 분석(사용자 사전), 동의어 통일, 불용어 제거
2. **토픽 수 결정**: 토픽 수별 적합 지표 비교, 후보 모형(K = 20~35)의 해석 가능성 검토
3. **STM 추정**: 장점, 단점 텍스트에 각각 추정
4. **해석**: 토픽별 대표 단어(`labelTopics`)와 대표 문서(`findThoughts`)로 토픽 이름 지정
5. **공변량 분석**: 총 만족도(1~2점 / 3~5점)에 따른 토픽 언급 비율 차이를 `estimateEffect`로 추정
6. **토픽 간 상관**: 토픽 상관 연결망(기준 r = .16) 시각화

## 주요 결과

- 장점, 단점 문서 19,954건에서 15개 토픽군 도출
- 가장 많이 언급된 장점: 워라밸, 직업 안정성
- 주요 단점: 수직적 조직문화와 상사의 비효율성, 보상 불만족, 잦은 업무 이동과 성장 기회 부족
- 토픽 간 연관: 상사의 비효율성과 불성실한 동료(고용 보장의 부작용), 부서별 업무강도 차이와 인수인계 부재
- 만족도에 따른 차이: 저만족 집단은 평판 관련 토픽을 더 많이 언급, 고만족 집단은 자기개발 기회를 장점으로, 저만족 집단은 성장 기회 부재를 단점으로 더 많이 언급
