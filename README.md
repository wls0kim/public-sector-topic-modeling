# 온라인 리뷰로 본 공무원의 공직 장단점 인식

## 개요

직장 평가 플랫폼에 공무원이 남긴 리뷰의 장점과 단점 텍스트를 구조적 토픽 모델링(Structural Topic Model, STM)으로 분석해, 공무원이 공직의 어떤 점을 장점과 단점으로 인식하는지 탐색했습니다. 리뷰의 총 만족도 점수를 공변량으로 넣어, 만족도가 높은 집단과 낮은 집단에서 토픽 언급 비율이 어떻게 다른지도 비교했습니다. 이 결과는 공공 부문의 고용 브랜드와 직원 가치 제안(EVP) 설계의 기초 자료로 의의가 있습니다.

## 자료

- 온라인 직장 평가 플랫폼의 공무원 리뷰 9,990건 (제목, 장점, 단점, 총점, 세부 평점, 작성 시기)
- 원자료와 수집 코드는 플랫폼 이용 약관에 따라 이 저장소에 포함하지 않았습니다.

## 분석 절차

1. **전처리**: 문장부호와 공백 정리, NLP4kec 형태소 분석(사용자 사전 적용), 동의어 사전으로 표현 통일, 불용어 제거
2. **토픽 수 결정**: 토픽 수별 적합 지표를 비교하고 후보 모형(K = 20~35)의 해석 가능성을 검토
3. **STM 추정**: 장점 텍스트와 단점 텍스트에 각각 모형을 추정
4. **해석**: 토픽별 대표 단어(`labelTopics`)와 대표 문서(`findThoughts`)를 저장해 토픽 이름을 지정
5. **공변량 분석**: 총 만족도(1~2점 / 3~5점)에 따른 토픽 언급 비율 차이를 `estimateEffect`로 추정하고 시각화
6. **토픽 간 상관**: 토픽 상관 연결망(기준 r = .16) 시각화

## 코드

| 파일 | 내용 |
|---|---|
| `code/01_preprocessing.R` | 원자료 정리, 형태소 분석(NLP4kec, 사용자 사전) 후 `blind.csv` 저장, 동의어 처리, 말뭉치 생성 |
| `code/02_stm_pros_cons.Rmd` | 최종 분석(01이 만든 `blind.csv` 사용): 장점과 단점 STM, 대표 단어와 문서, 공변량 분석, 시각화 |
| `code/03_thesis_stm.R` | 석사학위논문 분석: 공변량 없는 장점, 단점, 한줄평 STM과 대표 문서 |

실행에 필요한 파일(비공개): `blind_raw.csv`(01용 리뷰 원자료), `raw.csv`(03용 리뷰 원자료), `synonymDic.csv`(동의어 사전). 사용자 사전 `userDIC.txt`는 코드가 만듭니다.

## 코드 점검 (2026.11)

코드를 정리하면서 정리 전후 코드를 같은 자료로 실행해 결과를 대조했습니다. 분석 방법은 바꾸지 않았습니다.

- `02_stm_pros_cons.Rmd`: 정리 전후 실행 결과(공변량 계수, 대표 단어)가 일치
- `01_preprocessing.R`, `03_thesis_stm.R`: 점검 환경에 형태소 분석기(NLP4kec)를 설치할 수 없어 코드 검토와 문법 검사로 확인
- 고친 부분
  - `01_preprocessing.R`이 `02_stm_pros_cons.Rmd`의 입력인 `blind.csv`를 저장하지 않아 저장 단계를 넣음
  - `03_thesis_stm.R`: 파일 안에 남아 있던 코드 블록 기호 때문에 R이 파일을 읽지 못하던 문제, 지울 문서가 없을 때 자료 전체가 지워지던 문제, 대표 문서 엑셀에 문서 대신 행 번호가 저장되던 문제, `stm` 패키지에 없는 함수를 부르던 부분
- 같은 리뷰 자료를 보고서 형식으로 다시 분석한 수업 프로젝트는 [grad-coursework](https://github.com/wls0kim/grad-coursework)에 있습니다.
